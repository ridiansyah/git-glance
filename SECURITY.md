# Security Policy

## Supported Versions

Git Glance actively maintains and provides security updates for the latest released version.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within **Git Glance**, please help us protect the community by reporting it privately:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the maintainer or report via GitHub's Private Vulnerability Reporting on the repository (if enabled).
3. Please include:
   - A clear description of the vulnerability.
   - Steps to reproduce or a minimal proof of concept.
   - Affected environment details (OS, VS Code version, Git version).

You will receive an acknowledgment of your report within 48 hours, followed by regular updates until a fix is released.
